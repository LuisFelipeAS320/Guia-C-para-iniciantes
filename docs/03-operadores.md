# Operadores



## Operadores aritméticos



|Operador|Operação|
|-|-|
|+|Soma|
|-|Subtração|
|\*|Multiplicação|
|/|Divisão|
|%|Resto da divisão|



## Operadores relacionais



|Operador|Significado|
|-|-|
|==|Igual|
|!=|Diferente|
|>|Maior|
|<|Menor|
|>=|Maior ou igual|
|<=|Menor ou igual|



\*cuidado para não se confundir, = serve para atribuição de variáveis, enquanto == para comparação.



## Operadores lógicos



|Operador|Significado|
|-|-|
|\&\&|E|
|\|\||Ou|
|!|Não|



## Operadores de atribuição



|Operador|Exemplo|Equivalente|
|-|-|-|
|+=|x += 5|x = x + 5|
|-=|x -= 5|x = x - 5|
|\*=|x \*= 5|x = x \* 5|
|/=|x /= 5|x = x / 5|
|%=|x %= 5|x = x % 5|
