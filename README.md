# Guia de C para iniciantes



## Objetivo



Apresentar conceitos básicos da linguagem C de forma simples e prática, auxiliando iniciantes na preparação do ambiente de desenvolvimento e no aprendizado de conceitos fundamentais da linguagem.



O guia aborda a instalação do Dev-C++, funções básicas da biblioteca padrão <stdio.h>, operadores, estruturas de decisão e estruturas de repetição.



## Público-alvo



Pessoas começando em programação ou tendo o primeiro contato e que queiram aprender fundamentos da linguagem C.



## Pré-requisitos



conhecimentos básicos de informática e um compilador C instalado.





## Estrutura



O repositório está organizado em duas pastas principais:



\- docs/: contém os módulos do guia, com explicações sobre instalação do Dev-C++, entrada e saída de dados com <stdio.h>, operadores, estruturas de decisão e estruturas de repetição.

\- exemplos/: contém códigos em C que demonstram na prática os conceitos apresentados durante o guia.



Além dessas pastas, o repositório possui arquivos destinados à documentação do projeto e ao registro dos aprendizados adquiridos durante seu desenvolvimento.

## Como navegar



Para quem está começando, é recomendado acompanhar os conteúdos da pasta `docs/` na ordem em que são apresentados. O guia começa pela preparação do ambiente de desenvolvimento e avança gradualmente para os conceitos básicos da linguagem C.



Durante a leitura, os exemplos disponíveis na pasta `exemplos/` podem ser utilizados para colocar em prática os conceitos apresentados em cada módulo.
