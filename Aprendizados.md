# Aprendizados



Durante a realização deste projeto, pude colocar em prática vários conhecimentos que obtive através da conclusão dos módulos de Git e GitHub do TIC em Trilhas. Também consegui ter uma noção melhor sobre como organizar um projeto e fazer uso dessas ferramentas.



Primeiro, tive que pensar em como seria a estrutura do projeto para desenvolvê-lo da melhor forma possível e evitar que o histórico de commits se tornasse desorganizado devido a alterações planejadas de última hora. Depois que defini a estrutura, entendi a importância de fazer um README bem elaborado, pois, sempre que eu esquecia de algo ou não sabia como prosseguir, consultava o README e conseguia entender como avançar no projeto.



Além disso, entendi melhor como funciona o fluxo de trabalho com essas ferramentas, desde alterar ou modificar um arquivo, utilizar git add, realizar um git commit e depois enviar as alterações com git push, até fazer uso de branches e entender como realizar Pull Requests bem elaborados.



Um problema que percebi pouco tempo depois de já ter começado a estruturar o projeto foi ter interpretado de maneira errada como as branches deveriam ser utilizadas. Então, tive que repensar parte da estrutura e decidir como continuaria o desenvolvimento para demonstrar que havia entendido o funcionamento das branches e dos Pull Requests.



Durante o desenvolvimento do projeto, principalmente no início e nos primeiros commits, surgiram várias dúvidas relacionadas a pequenos erros que aconteciam durante o processo. Porém, já próximo ao final, percebi que conseguia avançar de maneira muito mais fluida e utilizar as ferramentas com mais confiança.



Além disso, durante a realização do conflito de merge, fiquei um pouco confuso ao tentar entendê-lo pela primeira vez, tanto em relação a como provocar o conflito de maneira controlada quanto a como resolvê-lo propriamente. No entanto, solucioná-lo se mostrou muito mais intuitivo do que eu imaginava. Essa parte também me ajudou a perceber que erros nem sempre são motivo para pânico e que manter a calma, analisar o problema e tentar entender o que aconteceu pode tornar sua resolução muito mais simples.
